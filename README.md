### NventaTech

Game mods and Linux desktop tools.

Mods for Cyberpunk 2077, Hytale, Brotato, Hades and other games, on Nexus Mods, CurseForge and Steam Workshop. On the desktop side: [cctop](https://github.com/nventatech/cctop), an AI usage and cost monitor for the KDE Plasma panel, and [DockPlus](https://github.com/nventatech/dockplus), a dock for Omarchy.
